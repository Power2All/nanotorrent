--- DESCRIPTION (max 10,000 characters) ----------------------------------------

NanoTorrent este un client BitTorrent mic și rapid care nu vă stă în cale.

Este o aplicație nativă scrisă în Rust, nu o pagină web într-o fereastră. Pornește instantaneu și folosește o fracțiune din memoria de care are nevoie un client modern obișnuit.

Fără cont. Fără reclame. Fără telemetrie, fără analiză, fără rapoarte de eroare. Nu se colectează nimic despre dumneavoastră sau despre ce descărcați. NanoTorrent este software cu sursă deschisă sub licența MIT, așa că acest lucru poate fi verificat, nu doar crezut pe cuvânt.

Adăugați torrente din fișiere sau linkuri magnet, urmăriți-le într-o listă pe care o puteți sorta, eticheta și filtra, și deschideți panoul de detalii pentru fișiere, parteneri și trackere. Sunt acceptate DHT, schimbul de parteneri, mai multe niveluri de trackere, trackerele UDP și torrentele private, iar conexiunile pot fi criptate, respingând la cerere tot ce nu este criptat.

Există mai multe moduri de a-l folosi. Fereastra de pe desktop este cel evident. O interfață web opțională, dezactivată implicit și protejată prin parolă, vă permite să comandați un client în execuție din browserul altei mașini. Iar fiecare setare este disponibilă în linia de comandă, ceea ce face NanoTorrent programabil și utilizabil pe o mașină fără ecran.

Puteți crea și propriile torrente, inclusiv BitTorrent v2 și hibride.

Steagurile de țară ale partenerilor provin dintr-o bază de date păstrată pe propriul calculator. Nicio adresă nu este niciodată căutată prin rețea.

Disponibil în 41 de limbi, cu teme deschisă și întunecată care urmează Windows.

NanoTorrent este o portare în Rust a PicoTorrent, de Viktor Elofsson.


--- WHAT'S NEW IN THIS VERSION (max 1,500 characters) --------------------------

Versiunea 0.3.4

- Torentele puse pe pauză nu își mai recreează fișierele la pornirea NanoTorrent. Un torent ale cărui date le ștersesei sau le mutasei putea reveni la 0% cu un dosar de fișiere goale.
- Interfața web primește acum actualizări în direct în loc să le ceară: reacționează instantaneu și consumă mult mai puțin procesor.
- Un indicator de conexiune arată dacă navigatorul mai are legătură cu NanoTorrent și se reconectează singur.
- Lista de torente din interfața web poate fi împărțită în pagini și sortată de-a lungul tuturor paginilor.
- Atât fereastra, cât și interfața web arată câți clienți web sunt conectați.
- Panoul de detalii se completează imediat ce dai clic pe un torent, în spatele unui strat de încărcare, nu după o secundă.
- Preferințele au fost refăcute după fereastra principală: file cu pictograme care derulează când nu încap, fereastră mai lată și bare de derulare care nu mai acoperă nimic.
- Preferințele arată limba pe care ai ales-o, iar fiecare fereastră deschisă schimbă limba când apeși Ok.
- Închiderea unei ferestre o închide acum cu adevărat, iar meniul Ajutor primește o legătură către documentația API pentru pluginuri.
