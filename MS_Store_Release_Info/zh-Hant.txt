--- DESCRIPTION (max 10,000 characters) ----------------------------------------

NanoTorrent 是一款小巧快速、不礙事的 BitTorrent 用戶端。

它是以 Rust 撰寫的原生應用程式，而不是包在視窗裡的網頁。啟動立即完成，佔用的記憶體只是常見現代用戶端的一小部分。

不需帳戶。沒有廣告。沒有遙測、沒有分析、沒有當機報告。不會蒐集關於您本人或您所下載內容的任何資訊。NanoTorrent 採用 MIT 授權開放原始碼，因此這一點可以查證，而不必只憑承諾。

從檔案或磁力連結加入種子，在可排序、可加標籤、可篩選的清單中檢視，並開啟詳細資料面板查看檔案、節點與追蹤器。DHT、節點交換、多層追蹤器、UDP 追蹤器與私有種子皆受支援，連線可以加密，並可選擇拒絕一切未加密的連線。

操作方式不只一種。桌面視窗是最直接的一種。選用的網頁介面預設關閉並以密碼保護，可讓您從另一台機器的瀏覽器控制執行中的用戶端。每一項設定也都能透過命令列使用，因此 NanoTorrent 可以撰寫指令碼，也能在沒有螢幕的機器上使用。

您也可以自行建立種子，包括 BitTorrent v2 與混合種子。

節點的國家/地區旗標來自儲存在您自己電腦上的資料庫。任何位址都不會透過網路查詢。

提供 41 種語言，淺色與深色佈景主題跟隨 Windows。

NanoTorrent 是 Viktor Elofsson 所作 PicoTorrent 的 Rust 移植版。


--- WHAT'S NEW IN THIS VERSION (max 1,500 characters) --------------------------

版本 0.3.3

- 嚴格網路模式：繫結 VPN 介面卡或使用 SOCKS Proxy 時，NanoTorrent 會關閉所有無法經由其傳輸的功能；介面卡不存在時拒絕啟動，消失時暫停所有種子。
- 繫結網路介面卡現在也可在 Windows 上使用。
- 狀態列會顯示接聽連接埠是否可連線，以及是否正在使用 Proxy 或已繫結的介面卡。
- 安全性修正：特製的種子檔案在 Windows 上可能寫入下載資料夾之外。
- 網頁介面新增桌面工具列、速度圖表、多重選取、可調整寬度的欄位以及拖放新增。
- 外掛程式現在也會出現在網頁介面中，並可在該處開啟與關閉。
- 網頁介面可在多次登入失敗後封鎖某個位址。嘗試次數、時間範圍與封鎖時長皆可設定。
- 修正了可能高於螢幕且無法捲動的視窗。
