--- DESCRIPTION (max 10,000 characters) ----------------------------------------

NanoTorrent は、邪魔にならない小さく高速な BitTorrent クライアントです。

ウィンドウの中の Web ページではなく、Rust で書かれたネイティブアプリケーションです。すぐに起動し、一般的な最新クライアントが必要とするメモリのごく一部しか使いません。

アカウントは不要です。広告はありません。テレメトリも、解析も、クラッシュレポートもありません。あなたについても、あなたがダウンロードするものについても、何も収集しません。NanoTorrent は MIT ライセンスのオープンソースなので、これは信じるしかない約束ではなく、確認できる事実です。

ファイルやマグネットリンクからトレントを追加し、並べ替え・ラベル付け・絞り込みができる一覧で状況を見守り、詳細パネルでファイル、ピア、トラッカーを確認できます。DHT、ピア交換、複数のトラッカー階層、UDP トラッカー、プライベートトレントに対応し、接続は暗号化でき、必要なら暗号化されていない接続をすべて拒否できます。

操作方法は一つではありません。デスクトップウィンドウはその代表です。既定では無効でパスワードで保護される任意の Web インターフェイスを使えば、別のマシンのブラウザーから実行中のクライアントを操作できます。さらにすべての設定はコマンドラインから利用でき、NanoTorrent はスクリプト化でき、画面のないマシンでも使えます。

BitTorrent v2 やハイブリッドを含め、トレントを作成することもできます。

ピアの国旗は、お使いのコンピューター上に保存されたデータベースから取得します。アドレスがネットワーク越しに問い合わされることは決してありません。

76 の言語で利用でき、Windows に追随するライトテーマとダークテーマを備えています。

NanoTorrent は Viktor Elofsson 氏による PicoTorrent の Rust 移植版です。


--- WHAT'S NEW IN THIS VERSION (max 1,500 characters) --------------------------
バージョン 0.4.1

- 設定を変えたり再起動したりしても、共有比がゼロに戻らなくなりました。
- 対応する動画プレーヤーが増えました: Media Player、MPC-HC、PotPlayer、SMPlayer、Celluloid、IINA、Elmedia Player。お使いのシステムにあるものだけが表示され、見つからない場合は場所を尋ねます。
- トラッカーへのアナウンスは、トレントが指定したとおり階層ごとに行われます。予備のトラッカーは予備のまま残ります。
- トレントの削除、トラッカーの変更や削除は、先に確認します。各質問には一度答えれば、その答えを記憶できます。
- PicoTorrent からの取り込みは先に確認し、現在の一覧を空にしたり設定を引き継いだりできます。何が入り、何がすでにあり、何が失敗したかを知らせます。
- Web インターフェイスがアプリに追いつきました: 種類ごとのアイコン付きファイルツリー、タブ化された詳細、自分の列幅を決めるアイコンボタン、そして横スクロールバーの解消。
- プラグインは独自のアイコンを持てるようになり、開くボタンと設定ボタンは常に表示されます。
- HTTPS では Web インターフェイスが何も変更できませんでした。どのボタンも拒否されていました。
- 幅が狭くなるとツールバーはメニューに畳まれ、長い項目名は切り詰められ、バックグラウンドのエラーも翻訳されます。
